## Data flow

1. `main.tsx` mounts the router and error boundary.
2. `useDashboard` resolves the route and URL filters, pins entity scope, validates dates and requests a summary.
3. `services/demoRepository` provides master records and collection queries. Its demo implementation uses `data/mock` and `domain` calculations.
4. `DashboardContent` passes the report to the corresponding page. Pages compose charts, tables and shared UI components.
5. `reports` and `utils/csv` use the same report data for complete export and print output.

Layout state such as sidebar collapse and the help dialog belongs to `DashboardLayout`. Table search, sorting and pagination belong to `EntityTable`. Reporting state belongs to `useDashboard`; it is not duplicated separately on each page.

## Import and dependency rules

- Use `@/` for imports rooted at `src/`. The alias is configured consistently in TypeScript and Vite; Vitest uses the Vite configuration.
- Pages and shared UI obtain demo records through `services/demoRepository`, not directly from mock generator files.
- `types` has no runtime dependencies. `utils` contains reusable, non-React functions.
- Collection rules belong in `domain`, never inside chart or table JSX.
- UI primitives do not import pages. Pages may use shared components; shared components must not import pages.
- Keep an entity's normal directory UI in `DirectoryView`. The three directory pages select their entity kind; changes shared by all three belong in the shared view.
- Add calculation tests under `tests/unit` and user-flow tests under `tests/integration`.

## Future backend integration

The current `CollectionRepository` is synchronous because all records are generated locally. For a backend, add an API adapter under `services/`, introduce asynchronous loading in the hook and replace the demo-specific network/entry dependencies used by domain queries. Keep typed records, status semantics and report aggregation contracts stable. No API keys belong in the browser bundle.

## Where to make common changes

| Change                                   | Location                                                  |
| ---------------------------------------- | --------------------------------------------------------- |
| Add a page or change navigation          | `pages/`, `app/navigation.ts`, `app/DashboardContent.tsx` |
| Change the overview layout               | `pages/OverviewPage.tsx`                                  |
| Change collection or no-supply rules     | `domain/collection.ts`, `domain/collectionStatus.ts`      |
| Change fake master records               | `data/mock/network.ts`                                    |
| Change date presets or filter validation | `domain/reportingFilters.ts`                              |
| Change a chart                           | `components/charts/`                                      |
| Change CSV fields                        | `reports/exportRows.ts`                                   |
| Change print layout                      | `reports/PrintReport.tsx`                                 |
| Change branding or responsiveness        | `components/ui/Logo.tsx`, `styles/globals.css`            |
